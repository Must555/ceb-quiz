🫁 Les appareils du corps

La règle

  • Digestif : bouche, œsophage, estomac, intestins, foie. Respiratoire : fosses nasales, trachée, bronches, poumons.
  • Circulatoire : cœur, artères, veines, capillaires. Excréteur (urinaire) : reins, uretères, vessie, urètre.
  • Locomoteur : os (le squelette), muscles, tendons, articulations. Système nerveux : cerveau, moelle épinière, nerfs.
  • Les 5 sens : la vue (yeux), l'ouïe (oreilles), l'odorat (nez), le goût (langue), le toucher (peau).

Exemple

Le crâne protège le cerveau ; les côtes protègent le cœur et les poumons.

💡 Astuce

Un appareil = plusieurs organes qui travaillent ensemble pour une même fonction.

Le groupe nominal

La règle

  • Le groupe nominal a pour noyau un nom.
  • Le noyau peut être précisé par un déterminant, des adjectifs, un complément du nom (de…, à…, en…).
  • Le déterminant et les adjectifs s'accordent avec le noyau, pas avec le nom du complément.

Exemple

le petit chien noir de Hugo → noyau : chien (masculin singulier).

Astuce

Le noyau est le nom qu'on ne peut pas supprimer.

Comprendre la règle

Le groupe nominal (GN) est un groupe de mots construit autour d'un nom : son noyau. Le plus petit GN est un nom seul (Bruxelles, Léa) ou un déterminant suivi d'un nom (le chien).

On peut l'allonger avec des expansions : un ou plusieurs adjectifs (le petit chien noir), un complément du nom introduit par un petit mot comme de, à, en, pour, sans (un pull en laine), ou une proposition qui commence par qui, que, où (le chien qui aboie). Pour trouver le noyau, enlève les mots un à un : le noyau est le nom qu'on ne peut pas supprimer.

Le déterminant et les adjectifs s'accordent avec le noyau, jamais avec le nom du complément : dans « des pots de confiture », « confiture » garde son propre accord. Et quand on remplace un GN par un pronom, le pronom prend la place du groupe entier.

Exemples expliqués

  • une maison → la grande maison → la grande maison blanche de mes grands-parents Le groupe s'allonge, mais le noyau reste « maison ».
  • « Les feuilles du vieux chêne sont tombées. » Le noyau est « feuilles » (féminin pluriel) : on écrit « sont tombées », pas « est tombé ».
  • « Le petit chien noir de Hugo aboie. » → « Il aboie. » Un seul pronom remplace les six mots du groupe.

Les pièges du CEB

  • Accorder avec le nom du complément : « la boite de crayons est rangée » (noyau : boite).
  • Prendre un adjectif pour le noyau.
  • Oublier une partie du groupe quand on le recopie : le complément du nom en fait partie.
  • Couper un GN quand on dit ce que remplace un pronom : la réponse attendue est souvent le groupe complet.

Ce que le CEB t'a déjà demandé

  • CEB 2017 · livret 1 · question 10 Recopier le groupe nominal complet qui désigne Tintin sans le nommer : « le héros créé par Hergé », avec « créé par Hergé ». Voir l'examen
  • CEB 2018 · livret 1 · question 18 Remplacer « les siens » par un groupe nominal qui garde le sens : « sa famille », « son troupeau » ou « les autres chevreuils » (pas seulement « sa mère »). Voir l'examen

Exercices corrigés

Essaie de répondre, puis ouvre la réponse. Dans l'application, ces exercices changent à chaque partie.

1Quel est le noyau du groupe nominal « ces jolies fleurs du jardin » ?○ jardin○ ces○ jolies○ fleurs

Réponse : fleurs
Le noyau est le nom « fleurs » : c'est le mot principal du groupe. Les autres mots (déterminant, adjectifs, compléments du nom) le précisent.

2Quel est le noyau du groupe nominal « ses grands yeux verts » ?○ verts○ grands○ ses○ yeux

Réponse : yeux
Le noyau est le nom « yeux » : c'est le mot principal du groupe. Les autres mots (déterminant, adjectifs, compléments du nom) le précisent.

3Quel est le noyau du groupe nominal « une grosse araignée velue » ?○ grosse○ velue○ araignée○ une

Réponse : araignée
Le noyau est le nom « araignée » : c'est le mot principal du groupe. Les autres mots (déterminant, adjectifs, compléments du nom) le précisent.

4Quel est le genre et le nombre du groupe nominal « des chaussures de sport neuves » ?○ masculin singulier○ féminin singulier○ masculin pluriel○ féminin pluriel

Réponse : féminin pluriel
Le noyau « chaussures » est féminin pluriel : tout le groupe nominal est donc féminin pluriel.

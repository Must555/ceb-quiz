Présent, imparfait, futur

La règle

  • Présent (1er groupe) : -e, -es, -e, -ons, -ez, -ent. (2e groupe) : -is, -is, -it, -issons, -issez, -issent.
  • Imparfait : -ais, -ais, -ait, -ions, -iez, -aient.
  • Futur simple : infinitif + -ai, -as, -a, -ons, -ez, -ont (aller → j'irai, être → je serai, avoir → j'aurai, faire → je ferai).

Exemple

chanter : je chante / je chantais / je chanterai. finir : nous finissons / nous finissions / nous finirons.

Astuce

Imparfait = « avant, d'habitude ». Futur = « demain ».

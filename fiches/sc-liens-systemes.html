Digestion, respiration, circulation : ensemble

La règle

  • Digestif : bouche → œsophage → estomac → intestin grêle → côlon → anus (glandes annexes : glandes salivaires, pancréas, foie). Les nutriments passent dans le sang au niveau de l'intestin grêle ; le côlon (la plus grande partie du gros intestin) absorbe encore de l'eau.
  • Respiratoire : nez ou bouche → trachée → bronches → alvéoles des poumons. Dans les alvéoles, le dioxygène passe dans le sang et le dioxyde de carbone en sort.
  • Circulatoire : le cœur pompe le sang ; les artères partent du cœur, les veines y reviennent. Le sang transporte dioxygène, nutriments, dioxyde de carbone et déchets.
  • Le dioxyde de carbone est rejeté par les poumons ; d'autres déchets sont filtrés par les reins et évacués dans l'urine.
  • Inspiration : le diaphragme s'abaisse, les côtes se soulèvent, la cage thoracique s'agrandit. Expiration : le diaphragme remonte, la cage thoracique diminue.

Exemple

Pour courir, le muscle reçoit le dioxygène (poumons → sang → cœur → artères) et les nutriments (intestin grêle → sang).

Astuce

Le sang est le « camion de livraison » qui relie les trois systèmes.

Comprendre la règle

Trois systèmes du corps travaillent ensemble. Le système digestif transforme les aliments en nutriments, qui passent dans le sang au niveau de l'intestin grêle. Le système respiratoire fait entrer le dioxygène : dans les alvéoles des poumons, il passe dans le sang, et le dioxyde de carbone en sort.

Le système circulatoire relie les deux : le cœur pompe le sang, qui part par les artères et revient par les veines. Le sang apporte à chaque muscle et à chaque organe le dioxygène et les nutriments dont ils ont besoin, et il emporte leurs déchets.

Pendant un effort, les trois systèmes accélèrent ensemble : on respire plus vite, le cœur bat plus vite, et les muscles utilisent plus de nutriments.

Exemples expliqués

  • Un muscle de la jambe pendant une course. Il reçoit le dioxygène (poumons → sang → cœur → artères) et les nutriments (intestin grêle → sang).
  • Le dioxyde de carbone produit par les muscles. Le sang l'emporte jusqu'aux poumons, et on le rejette en expirant.
  • Une tartine mangée le matin. Elle est digérée, puis ses nutriments passent dans le sang dans l'intestin grêle.
  • Les alvéoles pulmonaires. C'est là que se font les échanges de gaz entre l'air et le sang.

Les pièges du CEB

  • Croire que les nutriments passent dans le sang dans l'estomac : c'est surtout dans l'intestin grêle.
  • Croire que le dioxygène reste dans les poumons : le sang l'emporte partout.
  • Confondre artères (partent du cœur) et veines (reviennent au cœur).
  • Étudier chaque système seul, sans voir le rôle du sang qui les relie.

Exercices corrigés

Essaie de répondre, puis ouvre la réponse. Dans l'application, ces exercices changent à chaque partie.

1Vrai ou faux ? Les veines ramènent le sang des organes vers le cœur.

Réponse : Vrai
Vrai. Artères : du cœur vers les organes. Veines : des organes vers le cœur.

2Vrai ou faux ? Les artères transportent le sang du cœur vers les organes.

Réponse : Vrai
Vrai. Artères : du cœur vers les organes. Veines : des organes vers le cœur.

3Vrai ou faux ? Les artères ramènent le sang des organes vers le cœur.

Réponse : Faux
Faux. Ce sont les veines qui ramènent le sang vers le cœur ; les artères partent du cœur.

4Que se passe-t-il lors de l'inspiration ?○ Les côtes s'abaissent○ Le diaphragme se relâche et remonte○ Le diaphragme se contracte et s'abaisse○ La cage thoracique diminue de volume

Réponse : Le diaphragme se contracte et s'abaisse
Le diaphragme se contracte et s'abaisse. À l'inspiration, la cage thoracique s'agrandit : l'air entre dans les poumons.

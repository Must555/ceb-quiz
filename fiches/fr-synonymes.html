🟰 Les synonymes

La règle

  • Des synonymes sont des mots de même classe qui ont presque le même sens.
  • On les utilise pour éviter les répétitions.

Exemple

content = joyeux = ravi ; commencer = débuter.

💡 Astuce

Remplace le mot dans une phrase : si le sens reste le même, c'est un synonyme.

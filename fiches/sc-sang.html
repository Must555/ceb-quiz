Le sang

La règle

  • Le sang est formé d'un liquide, le plasma, dans lequel baignent les globules rouges, les globules blancs et les plaquettes.
  • Les globules rouges transportent le dioxygène ; ils donnent au sang sa couleur rouge.
  • Les globules blancs défendent le corps contre les microbes. Les plaquettes aident à boucher une plaie.
  • Le plasma transporte les nutriments et des déchets, comme le dioxyde de carbone, vers les organes qui les évacuent.

Exemple

Quand on se coupe, les plaquettes aident à former un bouchon (un caillot) : le saignement s'arrête.

Astuce

Le sang est le « camion de livraison » du corps : il apporte le dioxygène et les nutriments, il emporte les déchets.

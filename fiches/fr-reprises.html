Les reprises dans un texte

La règle

  • Pour éviter les répétitions, on reprend un nom par un pronom (il, elle, le, lui, celui-ci…) ou par un autre groupe nominal (cet animal, ce dernier…).
  • Pour savoir ce que désigne une reprise, relis la phrase d'avant.

Exemple

Julie a un chaton. Elle l'adore. → Elle = Julie ; l' = le chaton.

Astuce

Remplace la reprise par ta réponse : la phrase doit garder son sens.

Exercices corrigés

Essaie de répondre, puis ouvre la réponse. Dans l'application, ces exercices changent à chaque partie.

1Lis : « Une baleine s'est échouée sur la plage. Le gros mammifère a été sauvé par des volontaires. » Dans ce texte, que désigne « Le gros mammifère » ?○ la baleine○ un volontaire○ la plage

Réponse : la baleine
Dans ce texte, « Le gros mammifère » reprend « la baleine » : cela évite de répéter le même mot.

2Lis : « Le petit garçon regarde les oiseaux. Il les trouve magnifiques. » Dans ce texte, que désigne « les » ?○ ses yeux○ les oiseaux○ le petit garçon

Réponse : les oiseaux
Dans ce texte, « les » reprend « les oiseaux » : cela évite de répéter le même mot.

3Lis : « Le vieux pêcheur rentre au port. Le brave homme est fatigué. » Dans ce texte, que désigne « Le brave homme » ?○ le vieux pêcheur○ un poisson○ le port

Réponse : le vieux pêcheur
Dans ce texte, « Le brave homme » reprend « le vieux pêcheur » : cela évite de répéter le même mot.

4Lis : « Tom montre son dessin à Léa. Elle le trouve magnifique. » Dans ce texte, que désigne « le » ?○ Léa○ Tom○ le dessin

Réponse : le dessin
Dans ce texte, « le » reprend « le dessin » : cela évite de répéter le même mot.

Dans les vrais CEB

Questions posées à l'épreuve officielle, avec la réponse du corrigé.

1« Le cacaoyer est l'arbre qui produit les fruits à l'intérieur desquels se trouvent des graines appelées fèves de cacao. Celles-ci interviennent dans la fabrication du chocolat. » Recopie un mot ou groupe de mots qui désigne les « graines ».CEB 2024 · livret 8 · question 18

Réponse : fèves de cacao (aussi accepté : celles-ci, se)
Les graines sont appelées « fèves de cacao », puis reprises par « celles-ci ». « fèves » seul ne suffit pas : il faut « fèves de cacao » (ou le pronom « celles-ci », « se »).

2« Pour réaliser ce type de spectacle, les artistes de cirque doivent être à la fois athlètes, comédiens, danseurs… Chacun d'eux joue un rôle dans l'histoire tout en présentant un numéro. » « Chacun d'eux joue un rôle », cela veut dire que…○ un seul artiste joue un rôle.○ quelques artistes jouent un rôle.○ presque tous les artistes jouent un rôle.○ tous les artistes jouent un rôle.CEB 2023 · livret 4 · question 7

Réponse : tous les artistes jouent un rôle.
« Chacun d'eux » veut dire « chaque artiste, sans exception ». Tous les artistes jouent donc un rôle dans l'histoire, en plus de présenter un numéro.

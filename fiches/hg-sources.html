Les sources de l'historien

La règle

  • Source écrite : lettre, journal, charte, livre…
  • Source iconographique : image (peinture, photo, gravure, enluminure…).
  • Source matérielle : objet ou vestige (outil, monnaie, bâtiment, ruines…).
  • Source orale : témoignage, récit, chanson transmise de vive voix.

Exemple

Une photo de classe de 1920 est une source iconographique d'époque.

Astuce

Une source d'époque a été produite au moment des faits ; un livre ou un dessin récent sur les Romains n'est pas une trace de l'Antiquité.

Exercices corrigés

Essaie de répondre, puis ouvre la réponse. Dans l'application, ces exercices changent à chaque partie.

1Pour l'historien, une lettre écrite par un soldat dans les tranchées en 1916, c'est quelle sorte de source ?○ écrite○ iconographique○ matérielle○ orale

Réponse : écrite
C'est une source écrite : c'est une lettre.

2Pour l'historien, une lampe de mineur du 19e siècle, c'est quelle sorte de source ?○ écrite○ iconographique○ matérielle○ orale

Réponse : matérielle
C'est une source matérielle (un objet, un vestige) : c'est un objet.
